## 这不是一个让你「读书」的 App，而是让你「记录读书」的 App

区别很重要。

微信读书、京东读书，那些是书库，是内容平台，你得在里面买书或者订阅才能读。

「阅读记录」不一样，它不卖书，它管的是你读书这件事本身——不管你读的是纸质书、Kindle、还是微信读书，都能统一放进来记录。

你今天读了多久？读到哪页了？划了哪些句子？这本书你给几颗星？

这些东西，大多数阅读平台都做得很散，但「阅读记录」把它们整合成一套完整的个人阅读系统。

---

## 核心功能聊聊

**读书日历**是这个 App 最上瘾的地方。每天只要有读书记录，当天的日历格就会被点亮。从一个点，到一排，到整整一个月——那种日历慢慢被填满的成就感，比任何提醒推送都管用。

**阅读计时**也很贴心。打开 App，选择书，开始计时，这一段阅读就被记录下来了。不需要手动输入，也不需要看完才算，哪怕今天只读了 20 分钟，也是 20 分钟的读书人。

**OCR 书摘导入**是付费版才能无限使用的功能。拿手机对着书页拍一张，App 自动识别文字，转成可编辑的书摘保存下来。对读纸质书的人来说，这个功能省去了手动敲字的麻烦，实用程度拉满。

**书籍管理**支持通过搜索书名、扫描 ISBN 码添加书籍，还能打标签、分书架、标记阅读状态（想读 / 在读 / 已读），上千本藏书也能管理得井井有条。

**微信读书笔记导入**：如果你平时主要用微信读书，可以直接把笔记导进来，不用重复整理，两边数据打通。

## 它适合谁？

适合：
- 读纸质书、Kindle、多平台混读的人——需要一个统一管理阅读数据的地方
- 想培养阅读习惯、需要正反馈激励的人——读书日历打卡感很强
- 喜欢整理读书笔记和书摘的人——OCR + 多格式导出很好用

可能不太合适：
- 只用微信读书、不需要跨平台管理的人（微信读书本身已有数据统计）
- 纯粹找书看、需要书库的人（这个 App 不提供内容）
